# Design System: Spin the Block

## Overview

**Creative North Star: "Street game cabinet"**

This documents the implemented direction recorded in `index.html`: a street game table where land, luck, and duels meet. Dark asphalt surfaces surround a pale square board, painted district strips, condensed sporting type, lime controls, and an original isometric city. The cabinet carries the visual identity; the room and turn controls make the game playable. The expanded board, eight crews, and supporting settings, room, social, and profile panels continue this same world. Original hooded crew figures, named ownership badges, and illustrated buildings bring the same street materials to property play. Current rent arenas form a scoped Red Handed-inspired exception: gray outlined corridors, original black-and-white pixel fighters, red weaponry and visible red projectiles, inside the existing game dialog. The login front desk, six-city collection, and personal Map Studio extend the same street table: an authored city welcomes the player, painted district swatches distinguish maps, and compact editing rows make the board personal. Persistent board-side chat, readable trade reviews, and an optional eliminated-crew exit extend this same cabinet with direct operational controls.

The interface is dense around the board and more spacious around consequential actions. Friendly crew symbols and muted city colors give the original setting character without making players decode decoration. This is a record of the built system under the user's creative liberty. The user pinned Red Handed as the current rent-arena reference; this governs that combat surface only. No image-generation assets were supplied.

**Key Characteristics:**

- Asphalt and olive surfaces with pale, readable board pieces.
- Condensed display type paired with direct, compact interface text.
- Lime action and focus treatments; crew and district colors carry game meaning.
- An authored vector city inside a real, interactive perimeter board.
- Responsive controls-first play and explicit keyboard focus.
- Original vector board figures and pixel rent-arena fighters, with health, ammunition, ownership, and building states expressed in words.
- A city-led entry, painted map collection, and practical editing surface within the incumbent identity.
- Board-side conversation, explicit give/receive trade reviews, and a visible optional exit for eliminated crews.

## Colors

The palette combines desaturated street materials with clear painted accents. Frontmatter values are extracted from `src/style.css` and `shared/board.js`; the CSS remains the implementation source of truth. The root CSS custom properties are `--lime`, `--muted`, `--line`, `--panel`, `--ink`, `--secondary-text`, and `--secondary-border`. The latter two bind the existing secondary text and border colors to trade summaries and the eliminated-crew exit. Other listed colors are repeated literal assignments or functional board states. The sidecar's eight-step OKLCH ramps are synthesized previews for the design panel, not additional implemented colors.

### Primary

- **Lime:** Primary actions, current navigation, selected tiles, focus outlines, presence, and Grove Collective. The lighter hover tone belongs to primary buttons.

- **Arena Red:** Ready and fire actions and the rival health meter in the current rent arena. Weapon, projectile, and reticle art use nearby local red fills; these are renderer materials rather than replacements for the cabinet accent.

### Secondary

- **Sunset:** Sunset Syndicate, danger actions, risk cues, and offline status. Explain the consequence in words alongside the color.
- **Royals / Harbor / Night Owls / Northside Motion / Lowrider League / After Hours:** The remaining crew identities, alongside Grove Collective and Sunset Syndicate, make eight. Pair each crew color with its symbol and name. Equipped appearances can change an occupant token’s color and symbol; ownership bars retain the owner’s crew color.

### Tertiary

- **Low End / Eastside / Old Town / Heights / Downtown / Millionaire Row / Motion Mansion / Final Boss Row:** Eight district strips, district key entries, property heading rules, and property-list swatches. The first six token keys retain their incumbent names; the current district names are The Bodega Belt, Caught Lackin, The Trenches, Hit a Lick, Drip District, and Big Steppers. These identify land groups; crew colors identify players and owners.

### Neutral

- **Street Outline / Skin / Chain / Alley Backdrop:** Source-authored board figure materials and the legacy lane-shootout backdrop. The dark outline makes board silhouettes readable; skin and chain accents give figures character. The olive alley remains available to persisted lane duels.
- **Arena Floor / Ceiling / Ink / Paper:** The current rent arena uses grayscale perspective geometry, crisp dark contours, and pale fighter silhouettes and health. Wall faces are distance-shaded grays calculated by the raycaster. The control, translucent HUD, and message surfaces keep operational text distinct from moving geometry.

**The Arena Boundary Rule.** Arena Red marks current combat actions and weapon feedback; the board, city, login, and map surfaces retain their existing lime and district identities.

- **Asphalt / Panel / Action Panel / Crew Surface:** The page and functional surfaces. Active crews use a distinct olive surface and crew-colored border.
- **Text / Muted / Line:** Primary text, lower-emphasis text, and structural separation.
- **Field / Field Border / Field Text:** Editable room and trade values.
- **Board Frame / Board Center / Tile:** The board cabinet, inset city, and pale playable blocks. Hover, selected, occupied, corner, and mortgaged tile tones are separate functional states.
- **Modal / Good Card / Bad Card / Error Surface:** Outcome and interruption surfaces with corresponding readable text.
- **Panel Divider / Panel Label / Panel Support / Equipped Appearance:** The expanded panels use muted green separators, readable form labels and supporting copy, and an olive selected appearance row.
- **Owner Highlight:** A pale tile fill with an owner-colored outline marks the inspected player’s holdings.
- **Stoppa Rim / Sectors / Center / Number:** Muted green radial materials with light numeric labels and a lime pointer, preserving the cabinet’s game-object vocabulary.
- **Overlay Error / Text / Border:** A warm, readable error surface above dialogs.

The front desk intentionally extends the asphalt/olive family with Entry Asphalt, Entry World, and a restrained Entry Glow. Entry Paper warms the welcome lettering; Entry Copy, Support, Muted, and Tagline keep the supporting hierarchy within the same materials. Entry Field and its border are inset rather than floating. Entry Divider separates account choices. Map Card, Border, Copy, and Swatch frame painted city identities; selection reuses the existing Millionaire Row gold. These additions are deliberate surface roles, not a replacement palette. User-authored district colors are map data, not global UI tokens.

**The Ownership Rule.** Keep district and crew identity separate: a property's upper strip shows its district, its bottom strip shows its owner, and its hooded figures show occupants.

## Layout

The main cabinet is centered at a maximum width of 1580px. Desktop uses three columns: a 210px crew rail, a flexible board of at least 400px, and a 276px action rail, separated by a 26px gutter. Page padding is 32px 30px 22px. At 1500px and wider, the rails become 220px and 300px, the board minimum becomes 500px, and the gap becomes 32px. At 1180px and below, the rails and gutters tighten.

The default board is an 11 × 11 CSS grid with a square aspect ratio. Its 40 playable blocks form the perimeter; the city occupies columns and rows 2 through 10. Grid size derives from the supplied board length (`length / 4 + 1`), preserving the 8 × 8 layout for legacy 28-square matches. The desktop grid gap is 3px inside a 7px padded frame. Keep the whole board geometry intact when resizing.

At 980px and below, the crew list spans a row above a two-column board and action layout. The district key, sidebar tip, and add-seat rail control are hidden at this size. At 720px and below, the cabinet becomes a single column with **actions first, crews second, board third**. The header navigation hides; essential header actions remain. Mobile page padding is 20px 14px, the board frame uses 5px padding and a 2px gap, and primary buttons reach a 48px minimum height. The action panel has 25px padding. This order is visual CSS ordering; the document's underlying order remains crew, board, actions.

At mobile sizes the board sits in a contained horizontal scrolling viewport with a 780px minimum board width, keeping street names legible without widening the page. A swipe hint and **See full map** control explain the interaction. Expanded dialogs use the same 490px default width and 610px wide variant, constrained to the viewport and a 90dvh height with internal scrolling and contained overscroll. Selecting a tile on a viewport at or below 720px focuses its property-detail region and scrolls it into view. That region lives in the action rail and carries the expanded name, identity, economics, and management actions. Preserve this bridge between the compact board and readable controls.

The entry uses a two-column city/front-desk composition (`1.25fr` and `0.8fr`, with a 360px desk minimum). The world has 44px/64px padding and an 820px minimum height; the desk is capped at 660px with fluid horizontal padding. Below 640px, the entry stacks into a 365px city masthead above the account desk, with 24px horizontal insets. Map Studio inherits the 610px wide, viewport-constrained scrolling dialog. District and block grids use two columns with 8px gaps and become one column below 640px. Color inputs remain 42px wide. Verification forms wrap their input and button rather than widening the viewport.

The rent-arena dialog is a scoped exception to standard dialog width: `min(1000px, 96vw)`, `calc(100dvh - 24px)` maximum height, and 22px/24px padding. Below 600px it uses `calc(100vw - 20px)` width and 16px padding. The live canvas is 16:9 with a 50dvh height cap on desktop; narrow screens use 4:3 without that cap. Ready/result overlays require minimum canvas heights of 440px, 370px below 600px, and 430px below 360px so copy and the ready action fit; the modal retains internal scrolling. Combat actions wrap at 8px gaps, then form a two-column grid below 600px. Movement buttons use six columns on desktop and two below 600px.
